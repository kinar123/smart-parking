# חניון חכם

פרויקט הדגמה המציג לוח בקרה לכניסת רכבים לחניון. האתר מוגש באמצעות Nginx, ותמונות הרכבים מוגשות משרת Apache נפרד. שני השרתים פועלים במכולות Docker, והתמונות נשמרות ב־Volume.

כדי להפעיל את הפרויקט, מריצים בתיקייה:

```bash
docker compose up -d
```

לאחר ההפעלה, לוח הבקרה זמין בכתובת [http://localhost:8080](http://localhost:8080).
