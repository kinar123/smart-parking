# חניון חכם

פרויקט הדגמה לניהול ותצוגה של כניסת רכבים לחניון באמצעות לוח בקרה דינמי.

המערכת בנויה ממספר רכיבים:
- ממשק משתמש המוצג דרך Nginx
- שרת Apache המגיש את תמונות הרכבים
- שני שירותים שמופעלים כקונטיינרים ב-Docker
- שמירת נתונים ותמונות באמצעות Volume

## דרישות
- Docker
- Docker Compose

## הפעלה
כדי להפעיל את הפרויקט, פועלים בתיקיית הפרויקט:

```bash
docker compose up -d
```

## כיבוי
```bash
docker compose down
```

## עדכון השרת
אם שיניתם קבצים או בניתם מחדש את התצורה, אפשר להפעיל:

```bash
docker compose up --build -d
```

## גישה למערכת
לאחר ההפעלה, לוח הבקרה יהיה זמין בכתובת:

[http://localhost:8080](http://localhost:8080)
